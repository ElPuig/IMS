# Fixes:

## Guard duty board PDF export never marked a WC guard as WC:
- Developer report (Cari Castillo, Wednesday 8-9 WC guard): the printed guard duty board (both
  the schedule tab and the "Absences table" tab from #442) always showed a WC guard's name the
  same way as a plain guard's, with no way to tell the two apart - the on-screen board already
  shows a "(WC)" tag next to a WC guard's name, but the PDF report calls
  `get_guard_duty_board_lines()` directly rather than the JSON wrapper that computes that flag,
  so the marker was never rendered. Added the same `non_teaching.code == 'GWC'` check to the
  report template itself, in both tabs, so a WC guard now prints with a "(WC)" suffix next to
  their name, matching the screen.
